# 🖼️ Refero Styles & Real-World UI Patterns

Inspiration and design rules based on real-world top-tier SaaS and modern product interfaces curated by Refero Design.

## Pattern Catalogue
- **Hero Sections**: High-impact value proposition, clear primary CTA with glow or subtle border gradient, live interactive product preview card.
- **Feature Grids**: Bento-grid style layout with variable cell dimensions, crisp icons, subtle background gradients, and hover highlights.
- **Navigation Headers**: Sticky floating pill navigation bars (`backdrop-filter: blur(16px)`), clear active tab states, integrated quick search.
- **Form UI**: Floating label inputs, real-time validation badges, inline error helpers, disabled button states.
