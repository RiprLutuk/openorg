# 🎨 UI/UX Design System Skill

The **UI/UX Design System** skill ensures every user interface built or modified features world-class aesthetic quality, seamless user experience, responsive responsiveness, and modern interactive polish.

---

## 💎 Design Standards & Principles

### 1. Aesthetic Excellence & Color Harmony
- Avoid default HTML/browser styling or basic solid colors.
- Use curated HSL/OKLCH themes with soft gradients, subtle dark modes, glassmorphism (`backdrop-filter: blur(12px)`), and crisp borders (`1px solid rgba(255,255,255,0.08)`).
- Ensure high contrast and accessible text rendering against background elements.

### 2. Modern Typography & Layout Hierarchy
- Use modern font pairings (e.g. Inter, Outfit, Plus Jakarta Sans, Geist).
- Establish strong visual hierarchy: distinct `h1`/`h2` weights, balanced body lead text, and clean secondary labels.
- Utilize CSS Grid and Flexbox for fluid, mobile-responsive layouts.

### 3. Interactive Polish & Micro-Animations
- Add micro-interactions on hover, focus, and click (`transition: all 0.2s cubic-bezier(0.16, 1, 0.3, 1)`).
- Provide visual feedback for asynchronous states (skeleton loaders, animated spinners, optimistic updates, Toast notifications).
- Add smooth entrance animations for modal overlays and dynamic card grids.

### 4. Rich Media & Asset Generation
- Avoid low-effort filler placeholders or missing images.
- Use the `generate_image` tool when high-quality visual imagery, banners, or illustrations are needed.

### 5. Verification Checklist
- Check cross-device responsiveness (desktop, tablet, mobile viewports).
- Ensure full keyboard accessibility and proper ARIA semantic roles.
