# 📐 DESIGN.md Documentation Standard

Standardized layout and content guidelines for `DESIGN.md` files inspired by `designdotmd.directory`.

## Structure of a DESIGN.md File
1. **Design System Philosophy**: Core visual principles, target audience, aesthetic archetype (e.g. Modernist Swiss, Dark Glassmorphism, Industrial Brutalism).
2. **Color Palette & Tokens**: Semantic colors (Primary, Secondary, Surface, Border, Status) with OKLCH / HSL token values.
3. **Typography Scale**: Font families, line heights, letter-spacing, and font-weight hierarchy.
4. **Component Architecture**: Component anatomy, layout grids, spacing rules, and responsive breakpoints.
5. **Interactive States**: Hover, focus, active, disabled, and motion guidelines.
