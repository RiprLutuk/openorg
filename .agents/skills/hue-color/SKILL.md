# 🎨 Hue Color & Palette Generation Skill

Guidelines for color balance, harmony, and accessible contrast generation inspired by HueApp.

## Palette Rules
- **60-30-10 Rule**: 60% Dominant background/surface, 30% Secondary structure/typography, 10% Vibrant accent color.
- **Perceptual Contrast Ratio**: Maintain minimum WCAG AAA (7:1) for body text and AA (4.5:1) for headings and UI controls.
- **Harmonious Shades**: Generate color ramps by adjusting lightness and chroma in OKLCH/HSL space rather than applying arbitrary opacity overlays.
