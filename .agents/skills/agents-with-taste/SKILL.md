# 💎 Agents with Taste: UI Craft & Detail

Design guidelines focused on high visual craft, subtle micro-details, and pixel-perfect UI execution.

## Key Craft Rules
- **Subtle Borders**: Avoid harsh 1px solid black/gray borders. Use semi-transparent borders e.g. `border: 1px solid rgba(255, 255, 255, 0.08)` or inner shadows.
- **Layered Ambient Shadows**: Layer soft box-shadows with low opacity rather than heavy single shadows (e.g. `0 1px 2px rgba(0,0,0,0.05), 0 8px 24px rgba(0,0,0,0.1)`).
- **Tactile Hover & Active States**: Provide satisfying physical press depth (`transform: translateY(1px)` or `scale(0.98)` on button click).
- **Crisp Dark Mode Contrast**: In dark mode, elevate surfaces with lighter background shades rather than relying solely on shadows.
