## ⚡ 1. Superpowers & Engineering Standards
- **Never guess code logic or schemas**: Inspect source files using code search and `view_file` before writing code.
- **Empirical Diagnostics**: Read full, un-truncated error logs before diagnosing issues.
- **Empirical Verification**: Run verification commands (`bun run typecheck`, `bun run lint`, `bun test`) before completing tasks.
- **Subagent & Parallel Execution**: Delegate heavy tasks using `subagent-driven-development`, `dispatching-parallel-agents`, and research subagents.
